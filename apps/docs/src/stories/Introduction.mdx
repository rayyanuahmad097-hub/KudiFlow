# 🌉 KudiFlow Component Library

Welcome to the **KudiFlow UI Component Playground**! 

This interactive documentation allows you to explore, test, and understand all the UI components available in the KudiFlow ecosystem before integrating them into your application.

## 🎯 What You Can Do Here

- **🎨 Explore Components**:  Browse all available UI components in the sidebar
- **🎛️ Interactive Controls**: Test components with different props and states using the Controls panel
- **📋 Copy Code**: Get ready-to-use code snippets for each component
- **🚀 Live Preview**: See components in action with real-time updates
- **♿ Accessibility**: Check accessibility scores for each component

## 📦 Installation

To use KudiFlow components in your project:

```bash
npm install @kudiflow/ui
# or
pnpm add @kudiflow/ui
# or
yarn add @kudiflow/ui
```

## 🧩 Available Components

### Navigation
- **RouteCard** - Display route information with interactive elements

### Feedback
- **ProgressModal** - Show loading states and progress indicators

### Forms & Buttons
- **Button** - Customizable button component with multiple variants

## 🚀 Quick Start

1. Browse components in the sidebar (→)
2. Click on any component to see its documentation
3. Use the **Controls** panel to interact with the component
4. Check the **Code** tab to see usage examples
